# Inkite

> *Ink* 是落笔的痕迹，*Kite* 是放飞的想象——Inkite，让文字乘风而起。

## 项目简介

Inkite 是一款融合创意写作与社区分享的移动应用。把每日写作变成一场有温度、有反馈、充满游戏化乐趣的社区体验。通过词语提示激发灵感、以精美数字奖励强化习惯，Inkite 帮助用户在坚持写作的同时，将自己的想象力分享给整个世界。

## 核心功能

- **官方挑战**：应用定期发布由三个特定词语组成的官方提示，用户将这些词语融入短篇故事或日记，完成每日创作挑战。
- **通道广场**：故事完成后，用户可将作品发布到通道广场——一个开放的社区动态空间，供其他成员阅读、评论与推荐。高分作品将登上排行榜。
- **自由创作模式**：随机词语生成器为想要随时提笔的用户提供无限灵感，持续写作，持续互动。
- **展览厅（奖励系统）**：完成官方挑战即可赢取 AI 生成的精美折纸艺术品。随着参与度提升，用户可解锁魔法墨水（自定义公开故事的文本样式），以及风格各异的主题展示房间（如禅意花园、蒸汽朋克书房），用来陈列不断丰富的折纸收藏。
